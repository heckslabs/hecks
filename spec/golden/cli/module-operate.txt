operate — Run a domain and look inside it.

  hecks <Aggregate.command>! [name=value …]    do something
  hecks <Aggregate.query> [name=value …]       read something

everyday:
  Operation.run!           Dispatch a verb or a step list against a domain and keep what it…
  Operation.open_console!  Open an interactive console on a domain (also: console!)

commands:
  Operation:
    One thing an operator ran against a domain, and how it ended.
    run!                  Dispatch a verb or a step list against a domain and keep what it reported
    refresh_projections!  Bring every read-model projection of a domain up to date now
    redrive_outbox!       Redeliver the reactions a domain's outbox left undelivered, and name the claimed ones that stalled
    abandon_outbox_row!   Settle one stalled outbox row as failed, naming it by its delivery id, without running it
    run_behaviors!        Run a domain's behavior tests and keep the verdict
    open_console!         Open an interactive console on a domain (also: console!)
    smoke_test!           Dispatch one synthesized call per command and report of a wired domain
    smoke_http!           Check that a running service refuses bad signatures and accepts a good one
    bootstrap_admin!      Admit the first administrator of a domain's membership bluebook and grant them access
  Host:
    A running rust/host, and the version and era it last reported.
    check_era!            Ask a running host which era it reports, and keep whether it is one that should be running
    recheck!              Ask a host already checked which era it reports now

queries (nothing here changes anything):
  Operation:
    One thing an operator ran against a domain, and how it ended.
    follow            A domain's persisted event log past a cursor, for tailing it call by call.
  Introspection:
    A look at a booted domain, answered by the runtime without changing anything.
    ir                The IR a domain's boot produces, as JSON: what golden specs pin and an era hashes.
    shape             The storage shape an era's label is minted from: a bluebook file or a directory of them.
    stores            Every aggregate's current records, or one aggregate's, or one record: the head, not the journal.
    history           Every journal entry a domain's append-only adapters hold: the whole write history.
    statements        A bluebook's declared facts, as plain English sentences.
    undo              The command that undoes a declared command, from the bluebook's compensations, or that none is declared.
    narrate           A domain read back in English, whole or for one aggregate.
    relationships     How the contexts a domain holds depend on each other: shared kernel, customer/supplier, anti-corruption layer, subscription.
    context_map       A domain's declared context map drawn as a Mermaid diagram beside its wiring, with what holding the wiring to the map finds.
    world_skeleton    A starting .world for a domain: the settings and secrets its bound adapters declare, with no secret's value.
    docs              A domain's usage document, whole or for one aggregate.
    project_diagrams  A bluebook's Mermaid diagrams, as file names mapped to their text; nothing is written.
    glossary          A bluebook's Ubiquitous Language glossary, as file names mapped to their text; nothing is written.
