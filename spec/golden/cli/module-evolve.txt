commands:
  LanguageRun:
    One change to the language's own tables, or one reading of where its words stand.
    project_model!                Project the model's holding half from the language that declares it
    project_vocabulary!           Project the language's closed sets into the vocabulary
    project_rust_vocabulary!      Project the vocabulary tables into the Rust kernel, one enum a table
    project_refusal_wording!      Project the refusal template table, a second name of ProjectRustVocabulary
    project_reserved_names!       Project the Rust and Cargo reserved words into the codegen and build crates
    project_parser_table!         Project the Rust parser's keyword table
    project_phrase_table!         Project the Rust parser's sentence table from the Sentence bluebook's phrase rows
    project_bootstrap_table!      Project the DSL's bootstrap-window fallbacks from the keyword rows
    project_field_hints!          Project the host's form-field hints
    project_expression_tables!    Project the expression machinery's operator and normalisation tables
    project_reference!            Regenerate the DSL reference from the Syntax bluebook, keeping the committed prose
    propose!                      Enter a keyword row, proposed: it reaches no projection until admitted
    admit!                        Move a proposed keyword row to admitted
    deprecate!                    Move an admitted keyword row to deprecated
    retire!                       Move a deprecated or admitted keyword row to retired
    rename!                       Respell a keyword row; the old spelling keeps parsing
    propose_argument!             Enter an argument row of a keyword, proposed
    admit_argument!               Move a proposed argument row to admitted
    deprecate_argument!           Move an admitted argument row to deprecated
    retire_argument!              Move a deprecated or admitted argument row to retired
  CodemodRun:
    One rewrite of the example bluebooks by a codemod, or the rehearsal of it.
    hoist_local_givens!           Hoist a given that several commands of one owner repeat into one owner-level given
    drop_implicit_append_fields!  Drop an attribute line that only repeats what an append target element declares
    move_former_name!             Move an aggregate's formerly_known_as out of the bluebook into the world's stored_as
  ScriptRun:
    One named one-off script the checkout runs, planned or applied; the body is a tool.
    plan_script!                  Show what a named one-off script would change, writing nothing
    apply_script!                 Carry out a named one-off script's changes, only when confirmed

queries (nothing here changes anything):
  LanguageRun:
    One change to the language's own tables, or one reading of where its words stand.
    word_status  Where every word of the language stands: the ones not simply admitted, and the renamed.
  SyntaxBootCache:
    The grammar bluebooks' on-disk boot cache, keyed by a digest of the bluebooks it was built from.
    stale        Every cache whose grammar changed under it and is not yet rebuilt.
