queries (nothing here changes anything):
  Codebase.search       The lines of the checkout's text files that match a pattern, as path:line: text.
  Codebase.read_source  The numbered lines of one file of the checkout, whole or from one line to another.
  Codebase.outline      What a file declares, by line: each construct of a bluebook, each definition of Ruby.
  Codebase.declaration  Where a named construct is declared across the corpus, as path:from-to, with its text on request.
