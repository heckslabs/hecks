everyday:
  GateRun.gate!  Run every check of a stage, or the ones named, and keep whether the…

commands:
  GateRun:
    One run of a stage's checks: every check of the stage, or the ones named.
    gate!                       Run every check of a stage, or the ones named, and keep whether the gate is green
  ModelCheckRun:
    One static analysis over domains' models, and what it found: a check's history.
    model_check!                Check domains for dead states and unreachable steps, and keep the verdict
  ConformanceRun:
    One check that the engines, the reference docs and the argument gates agree with the language.
    check_engine_agreement!     Check that the query engines route every comparator through the one shared implementation
    measure_doc_coverage!       Check that every live word of the language has prose and a running example in the reference
    check_shape_ledger!         Check that no bluebook's storage shape moved without a translation edge, and rewrite the ledger when confirmed
    check_command_names!        Check that every launcher name a workflow, hook, gate row, spec or guide invokes is one the launcher accepts
    check_workflow_pagination!  Check that no workflow counts or waits on the items of a GitHub list call that returns only its first page
    argument_gate_matrix!       Generate the argument-gate ordering matrix; rewrite it and its fixtures only when confirmed
  StyleRun:
    One check or fix of comment style, or one document written with its keys in order.
    check_comments!             List every comment that breaks the Ruby style guide
    fix_comments!               Rewrite the mechanical Ruby comment violations
    shorten_value_objects!      Rewrite every bluebook value object block that only wraps one plain value as the shorthand
    write_comment_baseline!     Record every long comment block as tolerated, for lib/hecks unless paths are named
    check_comments_unchanged!   Prove an edit was comment-only: no file's code differs from the ref
    check_rust_comments!        List every comment that breaks the Rust style guide
    fix_rust_comments!          Rewrite the mechanical Rust comment violations
    canonicalise!               Write a JSON document with every object's keys sorted
  InspectionRun:
    One inspection of the Ruby by flog, flay, reek or rubycritic.
    flog!                       Rank the Ruby methods by complexity, worst first
    flay!                       Find Ruby code that is copied or nearly copied
    reek!                       List the design smells in the Ruby
    rubycritic!                 Write the combined quality report, with git churn
  Audit:
    One walk of a domain's journal chain from its latest seal, and whether every digest held.
    verify!                     Walk a domain's journal chain from its latest seal and say whether it was altered

queries (nothing here changes anything):
  StyleRun.report_comments       The Ruby comment violations, as summary tables, a list or JSON.
  StyleRun.report_rust_comments  The Rust comment violations, as summary tables, a list or JSON.
