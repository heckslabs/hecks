    check_coverage_allowlist!     Check that every rule excusing a Rust coverage gap still excuses a real one
  RegenerationRun:
    One regeneration of every corpus domain's committed Rust output, or the check that it is current.
    regenerate_corpus!            Regenerate the Rust output of every corpus domain or the ones named, or with check only compare it
    project_ci_gates!             Project the CiGate rows into the workflows' marked detector jobs, or with check only compare them

  KernelRun:
    One projection of the Rust kernel's capability enums, or one measure of their coverage.
    project_kernel_capabilities!  Project the capability enums the hand-written Rust kernel is matched against
    measure_kernel_coverage!      Check that every capability the grammar admits has its hand-written kernel file
  GateRun:
    One run of a stage's checks: every check of the stage, or the ones named.
    gate!                         Run every check of a stage, or the ones named, and keep whether the gate is green
  ModelCheckRun:
    One static analysis over domains' models, and what it found: a check's history.
    model_check!                  Check domains for dead states and unreachable steps, and keep the verdict
  ConformanceRun:
    One check that the engines, the reference docs and the argument gates agree with the language.
    check_engine_agreement!       Check that the query engines route every comparator through the one shared implementation
    measure_doc_coverage!         Check that every live word of the language has prose and a running example in the reference
    check_shape_ledger!           Check that no bluebook's storage shape moved without a translation edge, and rewrite the ledger when confirmed
    argument_gate_matrix!         Generate the argument-gate ordering matrix; rewrite it and its fixtures only when confirmed
  StyleRun:
    One check or fix of comment style, or one document written with its keys in order.
    check_comments!               List every comment that breaks the Ruby style guide
    fix_comments!                 Rewrite the mechanical Ruby comment violations
    write_comment_baseline!       Record every long comment block as tolerated, for lib/hecks unless paths are named
    check_comments_unchanged!     Prove an edit was comment-only: no file's code differs from the ref
    check_rust_comments!          List every comment that breaks the Rust style guide
    fix_rust_comments!            Rewrite the mechanical Rust comment violations
    canonicalise!                 Write a JSON document with every object's keys sorted
  InspectionRun:
    One inspection of the Ruby by flog, flay, reek or rubycritic.
    flog!                         Rank the Ruby methods by complexity, worst first
    flay!                         Find Ruby code that is copied or nearly copied
    reek!                         List the design smells in the Ruby
    rubycritic!                   Write the combined quality report, with git churn
  Audit:
    One walk of a domain's journal chain from its latest seal, and whether every digest held.
    verify!                       Walk a domain's journal chain from its latest seal and say whether it was altered
  AgentRun:
    One brief handed to a background Claude session: started and tracked, or refused with the reason.
    dispatch!                     Hand one brief to a background Claude session working in a directory
    check!                        Ask whether a started session is still working
    tidy!                         Remove the finished session of one run, unless it is unfinished or a person took it over
  Revision:
    One commit made in a checkout, or declined with the reason: what it says and what it is on.
    make!                         Commit what is staged in a checkout under a message: never pushed, never amended, never onto main
  LinkedTree:
    A linked worktree opened on a new branch from main, or declined with the reason.
    add!                          Open a linked worktree on a new branch from main, never on main itself
  Landing:
    One branch landed on local main, or one worktree retired: done, or refused with the reason.
    land!                         Merge a worktree's branch onto local main: fast-forward when it can be, a merge commit when main moved, never forced, never pushed
    retire!                       Remove a merged worktree and delete its branch, unless it holds uncommitted work or commits main lacks
  SendTrain:
    One push of a checkout's branch, taken in turn: carried by an earlier push, pushed, or refused.
    board!                        Push this checkout's branch once the push ahead of it lands, unless that push already carried it
    survey!                       List every checkout under a directory whose branch has commits its remote does not
  Shipment:
    One request to fix, gate, land and board a branch: the gate-and-board saga starts on it.
    ship!                         Start the gate-and-board saga for a branch: fix comment style, check the ledger, gate, land on main, board the push train
  ReviewRequest:
    One pull request opened or squash-merged on GitHub, and what GitHub answered.
    open!                         Open a pull request from a branch onto a base, and keep the number and URL GitHub gives it
    take!                         Squash-merge an open pull request by its number; never with an admin override
  LanguageRun:

    project_reference!            Regenerate the DSL reference from the Syntax bluebook, keeping the committed prose
    propose!                      Enter a keyword row, proposed: it reaches no projection until admitted

    deprecate!                    Move an admitted keyword row to deprecated
    retire!                       Move a deprecated or admitted keyword row to retired

    propose_argument!             Enter an argument row of a keyword, proposed
    admit_argument!               Move a proposed argument row to admitted
    deprecate_argument!           Move an admitted argument row to deprecated
    retire_argument!              Move a deprecated or admitted argument row to retired

    rust_domains            The feature and directory of every domain with a Rust feature.
    regen_order             The directories regeneration walks, in the order it walks them.
    corpus_rust_coverage    Whether every generated Rust module is routed by its domain.
    generated_key           The content hash of what regenerating the named domains reads: the generator and each domain's own sources.
    ir_constructs           The structural diff of each IR construct from its meta-domain.
    ir_duplicates           The rules declared more than once across the corpus.
    ir_impact               Which propagation touchpoints of a construct's field already show it.
  StyleRun:
    One check or fix of comment style, or one document written with its keys in order.
    report_comments         The Ruby comment violations, as summary tables, a list or JSON.
    report_rust_comments    The Rust comment violations, as summary tables, a list or JSON.
  Workspace:
    A look at a checkout: its branch, what it changed and what it committed.
    status                  The checkout's branch, whether it is a linked worktree, where it stands against main and origin/main, and what is changed or untracked.
    changes                 What the checkout changed since a ref (main by default): the diffstat, or the paths alone.
    history                 The commits in a range, newest first (the last 20 when none is named).
    settings                What this copy resolves for each setting that can come from a variable, its own world or a default, and which one supplied it. (also: config)
    doctor                  Whether this checkout can run Hecks here: overlay files parse, the stores answer, the toolchain pin matches, and what this worktree cannot see.
    where                   Where this checkout's domain resolves: the store each bluebook uses and why, the audience and environment with their reasons, and any overlay file this worktree lacks.
  Landing:
    One branch landed on local main, or one worktree retired: done, or refused with the reason.
    unlanded                Every branch with commits that are not on main, or with uncommitted work, and where its worktree is.
  ReviewRequest:
    One pull request opened or squash-merged on GitHub, and what GitHub answered.
    status                  The state of one pull request on GitHub: its number, state, URL and checks, as text.
  LanguageRun:
    One change to the language's own tables, or one reading of where its words stand.
    word_status             Where every word of the language stands: the ones not simply admitted, and the renamed.
  SyntaxBootCache:
    The grammar bluebooks' on-disk boot cache, keyed by a digest of the bluebooks it was built from.
    stale                   Every cache whose grammar changed under it and is not yet rebuilt.
  Codebase:
    A read of the checkout's text files, answered without changing anything.
    search                  The lines of the checkout's text files that match a pattern, as path:line: text.
    read_source             The numbered lines of one file of the checkout, whole or from one line to another.
    outline                 What a file declares, by line: each construct of a bluebook, each definition of Ruby.
    declaration             Where a named construct is declared across the corpus, as path:from-to, with its text on request.
  Era:
    One change to a domain's journal of eras, and how it ended: a store's upkeep.
    scaffold_translation    The edge file that would lead the latest held era to the current shape.
    audit_translation       The audit of the edge that leads the latest held era to the current shape.
    compose_translation     The one edge write_translation would write, and the stale edges it would delete.
    reconcile_plan          The dry run of Era.Reconcile: per domain, the held era, the current shape, the edge it would write, the edges it would delete, and the verdict.
    attestation             An era's held text as it now stands, and whether it still matches its digest.
    compaction              What compacting the domain's journals would delete, without deleting it.
    boot_status             The boot status of each bluebook under a domain directory: current, behind by a recorded implicit move, superseded, or unminted, with the held and current labels and the reason; read from its own database when it declares one, else from the committed ledger.
    boot_resolution         What a boot would resolve for each bluebook under a domain directory, from its own database: status, held label, current label, ordinal and reason.
    sqlite_status           The SQLite databases a domain's worlds name, read-only: per aggregate table the columns the aggregate declares and the table lacks (added on the next open), the columns it keeps that the aggregate no longer declares, and the tables no aggregate maps to.
  Seal:
    The head a domain's journal chain had when the rows before it were compacted away.
    latest                  The newest seal a domain holds.
  Operation:
    One thing an operator ran against a domain, and how it ended.
    follow                  A domain's persisted event log past a cursor, for tailing it call by call.
  Introspection:
    A look at a booted domain, answered by the runtime without changing anything.
    ir                      The IR a domain's boot produces, as JSON: what golden specs pin and an era hashes.
    shape                   The storage shape an era's label is minted from: a bluebook file or a directory of them.
    stores                  Every aggregate's current records, or one aggregate's, or one record: the head, not the journal.
    history                 Every journal entry a domain's append-only adapters hold: the whole write history.
    statements              A bluebook's declared facts, as plain English sentences.
    undo                    The command that undoes a declared command, from the bluebook's compensations, or that none is declared.
    narrate                 A domain read back in English, whole or for one aggregate.
    relationships           How the contexts a domain holds depend on each other: shared kernel, customer/supplier, anti-corruption layer, subscription.
    context_map             A domain's declared context map drawn as a Mermaid diagram beside its wiring, with what holding the wiring to the map finds.
    world_skeleton          A starting .world for a domain: the settings and secrets its bound adapters declare, with no secret's value.
    docs                    A domain's usage document, whole or for one aggregate.
    project_diagrams        A bluebook's Mermaid diagrams, as file names mapped to their text; nothing is written.
    glossary                A bluebook's Ubiquitous Language glossary, as file names mapped to their text; nothing is written.
  Release:
    One gem version: the record of what is running and what was shipped.
    shipped                 Every version that was tagged, published and verified.
  Registry:
    A bluebook registry repository: packages versioned in it and released as tags.
    check                   Judge every package against its latest release: a changed package needs a newer version and a changelog entry. (also: package.check)
    digest                  Print a package's content digest and shape labels, as its bluebook.lock records them. (also: package.digest)
  Package:
    One package of the bluebook registry, vendored into a project and pinned.
    verify                  Check every vendored package against its bluebook.lock, then describe them as the manifest a client image carries.
  TestSuiteRun:
