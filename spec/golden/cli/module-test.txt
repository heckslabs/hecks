  TestSuiteRun.run_changed!         Run the specs that the files changed since a git ref map to, in a folder
  TestSuiteRun.run_spec_example!    Run one spec file filtered to one example, through the test runner in…

commands:
  TestSuiteRun:
    One piece of work on the test suite: a listing, a baseline, a run or a fixture rewrite.
    run_spec_example!             Run one spec file filtered to one example, through the test runner in this process
    run_spec_files!               Run several spec files in one launcher boot, each in a new process or all in one, and report each file
    run_impacted_specs!           Map the branch's changed files to the specs they touch and run them, or list them when dry
    run_suite!                    Run every spec of a folder through the test runner in this process
    run_changed!                  Run the specs that the files changed since a git ref map to, in a folder
    stress_concurrency!           Rerun the thread-safety specs under many seeds, several processes at a time
    run_cargo_tests!              Run the cargo tests of the host, the parser or the JSON fuzzer, with the seed counts their fuzzers take
    clear_caches!                 Delete the on-disk syntax-boot and verdict caches, so the next boot builds and judges afresh
    regenerate_legacy_fixtures!   Regenerate the persistence legacy fixtures through the real adapters
    seed_semantics_corpus!        Fill the expected outcome of every semantics fixture that lacks one, or re-seed one
    write_io_parallel_spec_list!  Write the committed list of the spec files a tag filter selects
  FuzzRun:
    One fuzz sweep or benchmark, and how it ended; and the generated sequences it replays.
    fuzz!                         Fuzz a domain with generated sequences and keep whether anything broke a property
    mutate!                       Mutate a domain's rules and keep whether its checks noticed each change
    bench!                        Measure command throughput and latency for each target, and keep the report
