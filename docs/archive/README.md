# The archive

Each file here is a dated snapshot, never edited, banner required, not linked as current.

- **Dated snapshot.** The file records what was true on the day it was written.
- **Never edited.** A correction goes in a new file or in the code, not in the snapshot.
- **Banner required.** Every file opens with a `**Status:` or `**Historical snapshot`
  line in its first lines, naming its date. `spec/doc_banners_spec.rb` fails when one
  does not.
- **Not linked as current.** Nothing in the README, a guide or a status doc points at a
  file here as the current state of the project. A code comment or a plain-text
  citation may name one as the source of a decision.

A doc that is still the live answer to a question, such as the roadmap the README links,
stays in `docs/` with a banner instead. The decision is ADR 0070.
